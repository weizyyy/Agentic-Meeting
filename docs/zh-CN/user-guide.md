## 会议

页面加载后即显示最近一场会议，浏览记录不需要建立连接。
服务端设置了访问口令时，页面会先要求输入口令；本页没有进行中的会议时，顶部栏显示「退出登录」。
会议进行中登录过期的，页面上会盖一层口令输入框，会议本身不受影响。

| 操作 | 方式                           | 效果                         |
| ---- | ------------------------------ | ---------------------------- |
| 开始 | 「开始新会议」                 | 新建一场会议并接通麦克风     |
| 结束 | 「结束会议」                   | 把会议标记为已结束并断开连接 |
| 中断 | 关闭或刷新页面、网络断开       | 会议保留，状态为「已中断」   |
| 继续 | 会议横幅或会议列表中的「继续」 | 重新接入同一场会议           |
| 浏览 | 会议列表                       | 查看、重命名或删除以往的会议 |

**同一时刻只有一路连接。** 在另一个标签页或另一台设备上开始或继续会议，会接管当前连接；
原页面收到提示并转为只读。

**继续会议。** 时间轴从中断处接续，中断的空档会显示在字幕中（例如「— 中断了 12 分钟 —」）。
说话人名字、截图和任务都会保留；助理通过滚动纪要和最近十分钟的转录记得此前的讨论。
网络短暂中断时页面会自动重连，最多重试五次。

服务重启后说话人区分需要重新识别声音，同一个人可能得到新的标签，
此时在说话人标签上使用「合并到…」把两者合并。

**旁观。** 在另一台设备上打开同一地址，可以只读方式观看进行中的会议，页面每三秒刷新一次；
点击「在这台设备上继续」可把连接接管过来。

## 字幕与说话人

每行字幕显示两个时间：上方是浏览器所在时区的钟点，下方是会议进行的时长。
短暂的停顿不会把一句话拆成多行：同一说话人间隔不超过两秒的相邻片段会合并为一行。

说话人以标签的形式显示在字幕上方。

- **改名** —— 点击标签并输入名字，`session.members` 中登记的成员会作为候选。
  新名字对整场会议生效，助理看到的上下文也随之更新。
- **合并** —— 「合并到…」把一位说话人的全部发言并入另一位，合并后无法撤销。
- **修改个别字幕的说话人** —— 点击一行左侧的时间与说话人区域选中该行，或按住拖动选中连续的多行；
  此时上方的说话人标签成为归属目标，点击其中一个即可把选中的字幕归到该说话人名下，
  也可以选择「＋ 新说话人」。按 `Esc` 取消选择。字幕的文字区域不参与选择，仍可正常划选和复制。

## 与助理对话

**语音。** 先叫助理的名字，再说出要求，例如「Nova，总结一下最近十分钟」。助理用语音和文字回答，
之后回到待唤醒状态，因此追问时需要再叫一次名字。助理朗读时，直接开口即可打断。

助理可以直接完成的事情：

| 类型             | 示例                                       |
| ---------------- | ------------------------------------------ |
| 总结             | 「Nova，把到现在为止的讨论整理成三点。」   |
| 回忆             | 「Nova，王老师刚才是怎么说数据集划分的？」 |
| 查看屏幕         | 「Nova，这张图的纵轴是什么？」             |
| 回看之前的幻灯片 | 「Nova，前面那页经费预算里，哪一年最高？」 |

**文字。** 助理区底部的输入框可以直接提问，不需要唤醒词（`Enter` 发送，`Shift+Enter` 换行）。
文字提问只得到文字回答。助理忙碌时发送的消息会排队处理。

## 屏幕共享

在屏幕区点击「共享屏幕」，选择要共享的窗口或显示器。画面发生变化时自动截图，画面不变时每分钟截一张。
缩略图显示在时间线上：滚动鼠标滚轮可横向浏览，点击缩略图放大，放大后用 `←` `→` 切换。
每个新画面都会生成一段简短的摘要。

截图只在会议进行中上传；从其他设备访问时需要 HTTPS。

## 后台任务

对于耗时较长的要求（例如「Nova，查一下这篇论文的引用数」「把这三组数画成柱状图」），
助理会先口头确认，再交给后台 agent 处理，完成后在对话的间隙简要汇报。
通过文字交办的任务只以文字汇报。

任务面板显示进度。打开任务可以查看详细结果、来源、生成的文件，以及**这次任务向远端模型发送了哪些内容**。
进行中的任务可以取消，也可以向助理询问进度。

运行代码需要 Docker 沙箱；没有沙箱时 agent 仍可以检索和读图。

## 报告与导出

**报告。** 会议结束或中断后，切换到「报告」页签并点击「生成报告」。报告包含六个部分：
概要、讨论要点、结论与决议、待办事项、后台任务、截图索引，可以下载为 Markdown，也可以重新生成。

**导出。** 会议横幅提供三种下载，进行中的会议同样可以导出：

| 链接       | 内容                                                     |
| ---------- | -------------------------------------------------------- |
| 「转录」   | Markdown：滚动纪要、按时间排列的发言与画面摘要、任务结果 |
| 「JSON」   | 全部结构化数据                                           |
| 「完整包」 | 压缩包：转录、JSON、报告、全部截图和任务产物             |
