# 会议授权与有序事件恢复

`server.meeting_access=true` 时，唯一 `/api/sessions/{id}/events` 路由与 `WatcherHub` 保留 epoch/sequence、有界重放、快照、reset 及慢发送期限。每条订阅绑定不可变的登录和会议。游标只是恢复位置，不是权限：订阅前、快照/重放交付前及每个响应块发送前均复核授权。其他会议的游标最多触发所请求且已授权会议的 reset/快照。

删除成员、单登录/全部退出、登录到期，必须在一秒内关闭全部受影响的已开流，包括闲置或阻塞发送的流，丢弃队列并释放旁听者。再次登录必须重新授权订阅；其他用户及会议不受影响。下载和迟到 HTTP 响应保持当前授权复核。前端撤权清空视图及材料、关闭订阅、使在途请求 generation 失效，并丢弃旧事件游标；失权后不能渲染早先的重放/快照。

ASR/LLM/TTS 健康通知仍为全会事件；文本校验与排队通知只给请求者。保留 R02 interrupted/live 恢复。只有当前录音的精确 login 可用工具管线；其他已授权 host 与允许提问的 watcher 走有界、无工具问答。host HTTP 管理、迟到工具的不可变来源会议/login、CSRF、本地身份和 legacy 模式沿用 S04 契约。不引入第二个 hub、事件路由或可变 current actor。

验收使用真实 app 与假 HTTP 推理：两会、不同身份、跨会/过期游标、快照重放 reset 无越权材料、双流撤权/退出/到期、重新登录未获授权不能继承游标、阻塞发送释放且不影响另一会议。既有 S04 产物/RTC/迟到工具/预算及 R02 顺序/恢复/请求者通知场景继续有效。本说明是整合范围，不是验收或发布批准。

撤权释放服务端请求与订阅，不承诺收回已经到达客户端或进入 TCP 缓存的历史字节。若结束响应也被发送背压阻塞，最多再等 0.5 秒即取消并保留可见超时，不等既有通用 15 秒发送期限。
